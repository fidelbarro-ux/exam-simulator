No. 1) Which of the following qualities is MORE likely to be found in a tester's mindset rather than in a developer's?

a. A tester's mindset tends to grow and mature as the tester gains experience
b. Ability to see what might go wrong
c. Good communication with team members
d. Focus on getting all things done

Correct Answer: B
Explanation: A tester's mindset includes considering failure modes and risks.

No. 2) Which statement best describes unit testing?

a. Testing the complete application
b. Testing individual components in isolation
c. Testing network connectivity
d. Testing production deployment

Correct Answer: B
Explanation: Unit tests verify individual components in isolation.

No. 3) Which activity is most closely associated with identifying potential defects early?

a. Static testing
b. Production monitoring
c. Database backup
d. Release packaging

Correct Answer: A
Explanation: Static testing evaluates work products without executing the software.

No. 4) What is a useful benefit of independent testing?

a. It removes the need for developers
b. It can provide a different perspective on the software
c. It guarantees zero defects
d. It eliminates requirements

Correct Answer: B
Explanation: Independent testing provides a perspective separate from development.

No. 5) Which statement best describes regression testing?

a. Testing only new code
b. Testing whether changes have adversely affected existing functionality
c. Testing network cables
d. Testing user passwords

Correct Answer: B
Explanation: Regression test checks whether changes have harmed existing functionality.

No. 6) Which test level focuses on interactions between integrated components?

a. Unit testing
b. Integration testing
c. Acceptance testing
d. Installation testing

Correct Answer: B
Explanation: Integration testing focuses on interactions among combined components.

No. 7) What is a common purpose of acceptance testing?

a. To determine whether the system meets business needs
b. To compile source code
c. To configure a database user
d. To format a hard drive

Correct Answer: A
Explanation: Acceptance testing evaluates whether the system satisfies business needs.

No. 8) Which statement about defects is most appropriate?

a. Every defect is caused by a tester
b. A defect can remain undiscovered until testing or production
c. Defects only occur in user interfaces
d. Defects are always obvious immediately

Correct Answer: B
Explanation: A defect can remain undiscovered until testing or even production use.
